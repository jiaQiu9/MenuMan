**Instructions**
This is a game app that helps teach kid the basic functionality of the andorid devices(mobile and tables).
The user enters the app. 
The app will request the user to either log in (if they have an account) or sign up (to make an account).
After log in, the app will display the main screen, where there is a start button. 
Click the start button starts the game, and the minion men would run off the screen, and hide in one of the buttons.
For each level, the menu man would hid in a random button. 
In order to find the menu man, the user/ player has to perform some actions using their device(rotation, scroll, etc. ). 
After a certain amount of wins, there user wins, and a quote will be displayed. 
On the quote screen, the user has the option to restart the game.
